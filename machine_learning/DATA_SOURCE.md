# Data Source

The model is based on the public **Dataset of financial ratios of Slovak companies** by Drotár, Gnip, Zoričak, and Gazda (Mendeley Data, Version 2).

- DOI: 10.17632/j89csb932y.2
- Related article: *Small- and medium-enterprises bankruptcy dataset*, Data in Brief 25 (2019), 104360.
- License listed by the dataset repository: CC BY 4.0.

This project uses the manufacturing-sector records and 21 financial ratios observed over three prior years (63 model features).

See `DATA_DICTIONARY.md` and `artifacts/feature_definitions.json` for the feature mapping used by the integration layer.
